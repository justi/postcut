# Field notes

Monthly-ish write-ups about running postcut on real Rails projects. Not changelogs — those live in releases. Not roadmap — that lives in the main README. These are:

- What surprised me about offline LLM workflows this month
- What changed in the gem ecosystem since the last model cutoff I tracked
- What postcut got wrong and how I noticed
- What people asked for in issues / discussions and how it shaped the next version
- What I tried, what worked, what I dropped

Cadence: roughly every four to six weeks, depending on whether there's anything worth writing. Quality over schedule.

File names: `YYYY-MM.md` (the month I wrote the entry, not the month I covered).

If you find these useful or want to push back on something, open a discussion — these are notes, not opinions I'm precious about.

— Justi
